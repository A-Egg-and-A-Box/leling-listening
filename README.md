  - **通用版（改进版）**：https://a-egg-and-a-box.github.io/leling-listening/index.html

## 一、相比原版做了什么

| # | 改进点 | 说明 |
|---|---|---|
| 1 | 页面内嵌 B 站真实播放 | 每首曲子预先配好 B 站视频号（bvid），用 iframe 嵌官方播放器，**绝不用电子合成音冒充音乐** |
| 2 | 支持曲库以外的任意歌 | 内置「去 B 站搜」入口；也可以粘贴 B 站链接或 BV 号，直接把这首歌的录音嵌进本页来听 |
| 3 | 可选 AI 引导对话 | 自备服务商 API Key（存在本机 localStorage），开启后机器人会顺着你的回答继续引导；不填也能用内置引导脚本 |
| 4 | 「分段聆听」配真实时间点 | 每首曲子配好 3 句的进入时间，聆听卡上出现「▶ 从 m:ss 开始听「第一句」」，一点直接跳到该句 |
| 5 | 「只听这一句」到点自动停 | 起播后计时，到点自动把播放器停下来，不会一路放整首 |
| 6 | 乐龄版（适老化皮肤） | 大字号三档、高对比暖色、按钮铺满整行、语音朗读、一步一按钮、首页四步说明 |

## 四、怎么用

### 1. 听曲库里的曲子
打开任一版本 → 在首页挑一首 → 进入聆听卡 → 按「▶ 从 m:ss 开始听「第一句」」逐句听。

### 2. 听曲库以外的歌
1. 点「去 B 站搜任意歌」的入口，在 B 站找到那首歌；
2. 复制页面地址栏里「BV」开头的那串字符（或整段链接）；
3. 粘进「粘贴 B 站链接 / BV 号」框里，点确认 —— 这首歌就嵌进来了，同样可以一句一句听。

### 3. 开启 AI 引导（可选）
在页面里「AI 引导设置」填服务商的接口地址与 API Key（保存在本机浏览器，不上传）。
若服务商不允许浏览器直接跨域调用（如 Kimi），在本机跑一次代理即可：

```bash
UPSTREAM=https://api.moonshot.ai/v1 node llm-proxy.js
# 然后把「接口地址」填成 http://127.0.0.1:8787/chat/completions
```

> 页面主体（搜曲、B 站内嵌播放、内置引导脚本）完全不需要这个代理。

### 4. 乐龄版的朗读
- 顶部有「字号」小 / 中 / 大三档，选择会被记住；
- 语音朗读默认开启；**手机端第一次朗读需要你先点一下页面任意位置**（浏览器的安全策略要求朗读由用户手势触发）；
- 若这台设备确实没有中文语音包，按钮会变成「🔇 本机无朗读」，此时可以让旁边的家人照着屏幕念，或用手机系统自带的「屏幕朗读」。

### 5. 键盘操作
- `数字键` / `Tab`：在按钮之间移动与选择
- `Enter`：确认
- `Esc`：返回上一步

## 五、曲库

共 17 首精选 + 1 条「鉴赏其他曲子」模板，按三档难度排列：

- **入门 · 一听就耳熟**：彼得与狼、致爱丽丝、欢乐颂、卡农、茉莉花
- **进阶 · 听两遍才有味道**：蓝色多瑙河、二泉映月、月光奏鸣曲、梁祝、天鹅湖
- **欣赏 · 名曲慢慢听**：命运交响曲、沃尔塔瓦河、1812 序曲、图画展览会、自新大陆、培尔·金特 · 晨景、春之祭

时间点的配置原则：优先采用 B 站视频的官方分段或 UP 主简介里的时间轴；没有官方分段的曲目，按该作品主题在录音中常见的进入位置配置；存在十几秒误差的，页面提供手动微调入口。多乐章曲目（如《自新大陆》）直接跳转对应分 P。

## 六、技术实现

- **纯静态**：无后端、无构建、无框架，直接跑在 GitHub Pages 上。
- **真实音乐**：全部通过 `player.bilibili.com` 的 iframe 嵌入真实录音，每首预配 bvid。
- **两个关键取舍**：B 站 iframe 不提供播放控制接口，所以
  - 「跳到某一句」＝ 重载 iframe 并改 URL 参数（`&t=秒` 定位时间点、`&p=分P` 定位乐章）；
  - 「听完自动停」＝ 起播后启动计时器，到点把 iframe 重载为暂停状态。
- **AI 是可选项**：不填 Key 时，引导对话全部走内置脚本，离线可用。

## 七、已知说明与局限

- 音乐播放依赖网络与 B 站；音源若失效或受地区限制，可用「去 B 站搜」换一个源，不阻塞使用。
- 「到点自动停」的计时从播放器重载那一刻开始算，网络较慢时句尾会有偏差，因此文案统一写「约 N 秒」。
- 聆听记录保存在本机浏览器（localStorage），换设备或清理缓存会丢失。
- 曲库为 17 首精选，不是全量；自选曲目需要自己填每一句的起点。
